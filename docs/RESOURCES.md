# 本地资源与兼容性

源码构建不需要商业资源，可以独立生成经过校验的 BDA。要进入完整游戏，运行目录仍需五个资源；没有资源时不能把构建成功解释为可玩。

当前支持**导入已经转换好的 H1 资源**。工具不从网络下载游戏，不打开原版 EXE 执行，不把任意 RAR/PC 游戏目录自动当作兼容包。此前适配使用了人工确认的 GPT Image 背景以及本地字库，尚未提供从任意 PC 安装目录独立重建这些包的完整工具链；这是公开资源工作流的现有限制。

| 文件 | 大小（字节） | 用途 |
| --- | ---: | --- |
| FONT.BIN | 3,584,125 | `JOEYFNT1`，尺寸 8–32 的 25 个单色字形书，每书 2,154 字形 |
| H1UI.PAK | 12,617,296 | 卡图索引、三种卡图尺寸、卡名与效果 UTF-16 文本、界面素材 |
| H1ART.PAK | 801,200 | 480×272 棋盘与扩展素材 |
| H1SND.PAK | 14,551,040 | `JOEYSND1`，32kHz 单声道 IMA ADPCM 音乐和非语音音效 |
| H1SCN.PAK | 522,272 | 菜单和组牌两张完整 480×272 RGB565 背景 |

导入时对照参考清单校验所有五个文件，先完成校验再复制；不导入 SAV、固件、EXE 或压缩包里其他文件。构建再次校验哈希，避免新代码意外搭配不兼容的字形/纹理布局。修改资源格式后应同时修改原生读取器和版本检查，并重新验证。

`python tools/import_assets.py <JOEY目录>` 将兼容文件放到忽略的 `.local-assets/`。若该目录还含精确参考 `JOEY.bda`，工具按清单偏移提取本地桌面图标和两张 35×71 RGB565 剑形图像。提取的是使用者显式提供的 BDA；源码内没有这些像素。生成头文件只保存在忽略的本地目录。

`python tools/build.py --assets .local-assets --visuals reference --out build/reference` 必须产生参考程序 SHA-256 `0205b78eaff6ae4b77b091222fca9e54c6c5b6cdec04014428e56f0df7e6b31b`，否则构建失败。它保留本地完整版本的原有外观。

默认 `open` 视觉构建仅把程序内嵌的桌面图标和攻击指示替换为原创几何图像；界面布局、规则和外部素材读取保持同一实现。公开打包器拒绝 reference 构建和含外部素材的构建，防止将本地完整包误放入公开 Release。

移植没有包含原版 NPC 语音，原版完整命中 YGA 动画也没有全部重现；攻击指示使用整数旋转图像。卡牌规则完整性与这些表现范围分别记录。
