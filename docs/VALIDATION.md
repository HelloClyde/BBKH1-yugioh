## 重跑

```powershell
python tools/ci.py --cc <主机GCC路径>
python tools/test_mips.py --suite duel
```

第一条不需要原 PC 程序、商业素材或固件。第二条重新运行完整 MIPS 规则回归，速度比主机测试慢。完整固件验证需自备对应固件和资源，使用独立 NAND 副本并在每次读写前确认端口、进程、NAND 路径。CI 的 build job 不提供这些私人输入，不会将编译成功标为完整固件或真机通过。

规则测试覆盖已研究的效果族、原版数字对照矩阵、生命周期、连锁/选取/控制变化和批量完整对局。这些有界实验不穷举 1,115 条记录所有可能的组合；新发现的行为差异应先固定原版输入/输出，再加入回归。
